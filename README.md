# RAÍCES DE PLATA

Sitio web de una joyería dedicada a la belleza y elegancia de las piezas de plata.

## Contenido del proyecto
- `index.html`: página principal.
- `colección.html`: catálogo de productos.
- `producto.html`: detalles de los productos.
- `nosotros.html`: información de la marca.
- `contacto.html`: página de contacto.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript

## Publicación
Este proyecto se publica mediante GitHub Pages.
